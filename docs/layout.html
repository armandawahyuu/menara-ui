Layout

Admin shell

A fixed dark sidebar (256px) and a sticky topbar. Below 1024px the sidebar becomes a drawer opened by the burger button. Escape or the dimmed backdrop closes it.

Page header

.mn-page-head: breadcrumb and h1 on the left, actions on the right. Actions wrap under the title on phones.

Grids

  • mn-grid mn-grid-4: KPI row. 4 → 2 columns below 1100px.
  • mn-grid mn-grid-main: main column + side column (about 62/38). Stacks below 1100px.
  • mn-grid-2, mn-grid-3: even columns.
  • mn-stack: vertical rhythm inside a column.

Storefront

<body class="mn-shop"> + .mn-shop-header + <main class="mn-container"> (max 1120px). .mn-bottom-nav shows on phones only. Keep it to four items.

Breakpoints

  • 360px: smallest supported width. Nothing scrolls sideways.
  • 560px: topbar search hides.
  • 640px: forms become one column. KPIs get smaller.
  • 900px: store top nav ↔ bottom nav.
  • 1024px: admin sidebar ↔ drawer.
  • 1100px: multi-column grids collapse.

Rules

  • Tables scroll inside .mn-table-wrap, never the page.
  • Use cards for summaries and tables for lists people scan or sort.
  • One primary button per view.
  • Long names get .mn-cell-title (truncates) or wrap. Numbers get .mn-num and right alignment.
