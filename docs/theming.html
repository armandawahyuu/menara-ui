Theming

Every color, size and shadow is a CSS custom property in css/tokens.css. Components never use raw colors, so changing a token changes the whole UI.

Rebrand in a few lines

Override the brand tokens after tokens.css:

:root {
  --mn-primary: #0f766e;        /* buttons, links, focus, active nav, charts */
  --mn-primary-hover: #0b5f59;
  --mn-primary-soft: #e6f4f2;   /* tinted backgrounds */
  --mn-primary-text: #0f766e;   /* primary used as text on light surfaces */
  --mn-accent: #ffc83d;         /* highlights, current bar, badges */
}
:root[data-theme="dark"] {
  --mn-primary: #2dd4bf;
  --mn-primary-text: #5eead4;
  --mn-brand-surface: #134e4a;  /* store header + hero in dark mode */
}

Dark values also live under @media (prefers-color-scheme: dark) in tokens.css. Change both blocks, or delete the media block if you only want an explicit toggle. Try colors live on the gallery page, and check contrast: text on --mn-primary uses --mn-primary-ink.

Dark mode

Dark mode follows the operating system by default. A data-mn-theme-toggle button switches it and remembers the choice in localStorage (key mn-theme). To force a theme, set the attribute yourself:

<html lang="en" data-theme="dark">

Keep the small data-mn-theme-init script in <head>. It applies the saved theme before the first paint, so dark-mode users never see a white flash.

Typography

Rubik from Google Fonts, falling back to the system font. Sizes run from --mn-text-xs (12px, the minimum) to --mn-text-3xl (40px). Body text is neutral ink, not brand blue. Use .mn-num for tabular numbers in tables and KPIs.

Spacing, radius, shadows

A 4px grid: --mn-space-1 (4px) to --mn-space-8 (48px). Radius --mn-radius-sm|md|lg|pill. Shadows --mn-shadow-sm|md|lg.
