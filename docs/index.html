Getting started

Menara UI is plain HTML, CSS and a small script. There is nothing to install or build. Copy the files, link them, and start from the page closest to what you need.

1. Get the files

git clone https://github.com/armandawahyuu/menara-ui.git

Or download the ZIP from GitHub. Open index.html in your browser to see every template.

2. Copy three files into your project

  • css/tokens.css: colors, type, spacing (edit this to rebrand)
  • css/menara.css: all components
  • js/menara.js: theme toggle, mobile sidebar, modal, tabs, copy, select-all, countdown, and the icon sprite

3. Add them to your page

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My app</title>
  <!-- 1. Apply the saved theme before paint (prevents a light flash in dark mode) -->
  <script data-mn-theme-init>try{var t=localStorage.getItem('mn-theme');if(t)document.documentElement.setAttribute('data-theme',t)}catch(e){}</script>
  <!-- 2. Font (optional: falls back to system-ui) -->
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Rubik:wght@400;500;600;700;800&display=swap">
  <!-- 3. Menara UI -->
  <link rel="stylesheet" href="css/tokens.css">
  <link rel="stylesheet" href="css/menara.css">
</head>

Load the script at the end of <body> with defer:

<script src="js/menara.js" defer></script>

4. Start from a template

Copy the closest page from admin/ or store/ and replace the dummy data. Every page uses only mn- classes, so it works the same in Laravel Blade, Django templates, Rails, Express views or static HTML.

Using it with a framework

  • Laravel: put the folders in public/ and use asset('css/menara.css'). Move the sidebar into a Blade layout.
  • Django / Flask: put them in static/ and the shell in base.html.
  • React / Vue: import the two CSS files once. Keep the class names and skip menara.js if your framework handles the behaviour (you still need an icon solution).

Using it with an AI agent

Copy skills/menara-ui/ into your project’s .claude/skills/ folder (or your agent’s skills folder). The skill teaches the layout, type, color and component rules so new pages stay consistent.

Translating

All text lives in the HTML. Change lang="en" on <html> and translate the copy. The only strings in menara.js are the theme button labels, “Copied!”, “Copied to clipboard” and “Expired”.

Editing the templates in this repo

The HTML pages are generated by tools/build.py so the sidebar and headers stay identical everywhere. If you contribute, edit tools/pages/, then run python3 tools/build.py && python3 tools/check.py. If you only use the template, ignore this and edit the HTML directly.
