# Changelog

All notable changes to Menara UI are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

First public release.

### Added
- Design tokens (`css/tokens.css`) with light and dark themes, brand, status, chart and sidebar colors, a type scale, spacing, radius and shadows.
- Components (`css/menara.css`): app shell with responsive sidebar drawer, cards, KPIs, buttons, form fields, switches, badges, alerts, tables with bulk actions and pagination, tabs, segmented filters, modal, dropdown, toast, CSS bar charts, meters, funnel, empty states, login and error layouts, and storefront blocks (banner, header, hero, trust strip, product grid, ticker, compare table, steps, FAQ, bottom nav, checkout summary, QR, countdown, code reveal).
- `js/menara.js`: theme toggle with no-flash init, mobile sidebar, modal focus return, keyboard tabs, copy to clipboard, select-all with bulk bar, dismiss, countdown, toast and a 49-icon sprite.
- 10 admin pages and 5 storefront pages with neutral demo data.
- Gallery with a live brand-color picker, a docs site (getting started, theming, components, layout, accessibility), and README in English and Indonesian.
- `skills/menara-ui`: AI agent skill covering layout, typography, color, components and anti-patterns.
- Dev tools: page generator, repo checker, screenshot/overflow test and behaviour test.
